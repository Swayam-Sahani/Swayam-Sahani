# Page Plan

## Grammar choice

**Chaptered editorial.** The user asked for distinct scenes and a premium-minimal presentation. The page has a readable argument to make: introduce Swayam, explain the SEO experience, show the method, invite contact, and reserve proof for verified testimonials. The page will use separate editorial chapters with hard changes of ground, not one continuous scene.

Other grammars considered:

- **Filmic one-shot:** rejected because the user requested distinct scenes and section navigation.
- **Live surface:** rejected because there is no real software product to operate; a fake dashboard would be dishonest.
- **Continuous world:** rejected because it conflicts with the user's explicit request for distinct scenes.
- **Typographic poster:** rejected because the site needs practical information, an SEO method interaction, and future work/proof areas, not type alone.
- **Gallery / catalog:** rejected because the opening task is to establish Swayam's approach and build trust; there are no completed project objects to fill a project collection yet.
- **Split stage:** rejected because the offer is not a comparison between two equally real alternatives.
- **Rhythmic cutlist:** rejected because the user's premium-minimal direction and need to explain experience call for a measured read, not a loud rapid sequence.

## Navigation and scene rules

- A marginal folio/index identifies the current chapter and links to the requested sections; no fixed top bar.
- The title page stays typographic and light, with the user's supplied portrait as a small, replaceable editorial anchor alongside the introduction.
- Every chapter is a distinct ground and has a clear beginning and end.
- The close is a resolved contact colophon. The requested CTA links to the supplied LinkedIn profile as the current replaceable contact route; this opens LinkedIn and does not claim a confirmed meeting.
- The user-requested Contact-before-Testimonials order will be retained. The final review chapter resolves with a repeat link to the contact CTA.

## Signature move

**Search intent becomes an enquiry path.** A visitor chooses a clearly labeled illustrative search intent. A small editorial map updates the need, the recommended page structure, and the next action as one connected route. No metrics or client outcomes are claimed. The visitor's chosen example remains selected while they explore the path.

## Fingerprint gate

The personal registry is empty, so this is the first registered build and there are no existing rows to compare. The design will still use the following distinctive fingerprint: chaptered editorial grammar, a non-fixed margin folio, a typographic title-page opening, a search-intent-to-enquiry interaction, and a contact colophon with a verified-proof ending.

## Journey and score

| Beat | Intended feeling | Device / interaction | Purpose |
|---|---|---|---|
| Work / introduction | Curiosity | `flow` + `in`; static layered type/graphic composition | State who Swayam is and what the work is for, without a generic hero animation. |
| SEO experience | Recognition, then confidence | `reveal` at the chapter cut; `count` only for the stated five years | Connect real SEO experience to the site's purpose. |
| Projects / method | Possibility, then the emotional peak | `parallax` in a separate media/diagram column; bespoke Search Intent Path interaction | Make the claimed difference tangible without pretending to show client work. |
| Contact | Resolve | Editorial flow into a contact colophon | Invite one clear action: “Let’s discuss business face to face”. |
| Testimonials | Reassurance | `reveal` for an honest review empty state or real entries | Reserve a place for approved testimonials and Google Reviews. Never show invented quotes. |

The curve has no adjacent repeated feeling. The Projects / method scene is the peak and receives the greatest visual emphasis. A brief still pause before the path resolves is authored anticipation, not a missing asset or dead scroll.

Four device families are present across the page: `flow`, `reveal`, `count`, and `parallax`. The sequence does not use `pin`, `scrub`, `magnet`, or a full-bleed media hero, which chaptered editorial forbids.

## Visual and asset plan

- Use the existing Option B tokens: `#FAF7F0` ivory, `#3478D4` blue, `#182235` ink, `#78869A` slate, and white surfaces.
- Editorial stills use bright, natural light, real materials, restrained grain, and visible negative space for layout.
- Use a replaceable wordmark instead of inventing a complex logo.
- Keep the site complete without remote/generated images: use the shared portrait as a replaceable opening image, and use a local CSS/SVG editorial diagram for the method interaction.
- Supply `image-prompts.json` for a future high-resolution portrait and supporting editorial images. Do not generate fictional client sites, mock results, testimonials, or badges.

## Open implementation details

- No contact email, phone, booking URL, Google Business Profile, case studies, or testimonials were supplied. The LinkedIn URL from the notes is the only configured contact destination.
- Reviews and project content must use an editable data model and remain visibly empty/clearly labeled until real content is entered.
- FFmpeg preflight passes with the installed Essentials archive (539 filters and libwebp encoder). The matching Next.js WASM compiler is used because the Windows native SWC binary fails to load here. TypeScript and production build pass; desktop, mobile, and reduced-motion capture report no dead scroll. The intent-path control updates correctly and the browser run produced no page errors. Headless verification does not cover a physical phone.
